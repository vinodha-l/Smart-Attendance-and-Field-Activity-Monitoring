# Smart Attendance and Field Activity Monitoring

Student 1 Flutter mobile frontend for field workers.

## Included screens

- Mobile OTP login with password fallback
- Daily dashboard and assigned tasks
- Attendance workflow with GPS, photo and verification states
- Field activity reporting with rear-camera evidence and offline-sync status
- Attendance history and worker profile

## Run

1. Install Flutter and Android Studio.
2. Open `mobile-app`.
3. Run `flutter pub get`, then `flutter run` on an Android device or emulator.

The app uses a BHIM-inspired Indian tricolour interface, Tamil and English, GPS, front-camera attendance selfies, and SQLite offline storage. See [the Student 1 integration guide](docs/student-1-integration.md) for the agreed six-module contract and demo sequence.
